## An application layer mesh networking implementation in Python!

Features include:
  - Completely decentralized text communication & file transfers
  - Custom gossip protocol implementation for decentralized network discovery & node propogation
  - Custom multi-hop implementation with distance vector routing
  - End to end RSA encrypted direct messages
  - Hybrid encrypted (RSA + AES) custom UDP file transfer implementation for sending any and all files between Nodes
  - Custom user selected usernames (aliases)
  - [COMING SOON] a sleek, classic terminal interface!

This was mostly a project done for my own interest in exploring mesh networking, live chat apps, and custom file transfers!
I wanted to get, from a Python perspective, decently low level into designing my own routing and file transfers.
